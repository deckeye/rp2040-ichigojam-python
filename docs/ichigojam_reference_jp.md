# IchigoJam BASIC 総合リファレンス (ver 1.5対応)

IchigoJam BASIC特有の仕様、全コマンドの構文、省略形、および記述パターンを網羅したリファレンスです。

---

## 1. IchigoJam BASIC 独自の仕様と制限

他の一般的なBASIC（MSX BASICやN88-BASIC等）とは異なる、IchigoJam独自の重要な仕様です。

### 数値と変数
- **16ビット整数のみ**: 扱える数値は `-32768` から `32767` までの整数のみです。
- **浮動小数点数なし**: 小数は扱えません。割り算（`/`）は整数除算（切り捨て）となります。
- **変数名の制限**: 変数は `A` から `Z` までの26個（大文字・小文字区別なし、1文字のみ）です。
- **配列**: `[0]` から `[101]` までの102個が標準で使用可能です。

### 文字列
- **固定変数なし**: `A$` のような文字列専用変数は存在しません。
- **ポインタとしての扱い**: 文字列を変数に代入すると、その文字列が格納されている**メモリのアドレス（ポインタ）**が変数に格納されます。
- **記述**: `" "`（ダブルクォーテーション）で囲みます。

### プログラム記述
- **行番号**: `1` から `32767` まで。行番号のみの入力でその行を削除。
- **マルチステートメント**: `:`（コロン）で区切ることで1行に複数のコマンドを記述可能。
- **最大文字数**: 1行は32文字、プログラム全体は約1KB（1024バイト）に制限されています。

## 2. 記述のパターンと数値表現

### 数値の表記
- **10進数**: 通常の数値（例: `100`）
- **16進数**: `#` を付与（例: `#FF`, `#C00`）
- **2進数**: `` ` ``（バッククォート）を付与（例: `` `11110000 ``）

### 制御パターン
- **IF文**: `IF 条件 THEN 処理1 ELSE 処理2`
    - `THEN` は省略可能（例: `IF A=1 B=2`）。
    - 0以外を「真」、0を「偽」として扱います。
- **ラベル**: `@LABEL` 形式で定義。`GOTO @LABEL` 等でジャンプ可能。

## 3. コマンド省略形のルール

### 公式に定義されている省略形
| 元のコマンド | 省略形 | 備考 |
| :--- | :--- | :--- |
| `PRINT` | `?` | 最も多用される省略形 |
| `NOT` | `!` | 否定演算子 |
| `REM` | `'` | コメント（アポストロフィ） |
| `LOCATE` | `LC` | 座標指定 |
| `GOSUB` | `GSB` | サブルーチン呼び出し |
| `RETURN` | `RTN` | サブルーチンからの復帰 |

### ドット形式（L., R. 等）について
> [!IMPORTANT]
> **ドット形式の省略（L. for LIST, R. for RUN 等）は、IchigoJam BASICの標準仕様（ver 1.0〜1.5）には存在しません。**
> 
> 他のレトロPC系BASIC（SHARP MZ等）では「ユニークな頭文字 + ドット」でコマンドを省略できる規則がありましたが、IchigoJamでは独自の1文字（`?` 等）またはキーワードの短縮（`LC` 等）が公式な方法です。
> ※ただし、ファンクションキー（F1〜F5）に `LIST` や `RUN` が割り当てられており、ワンキー入力は可能です。

## 4. `OUT` コマンドの多様な記述

`OUT` コマンドは引数の数や値によって動作が大きく変わります。

| パターン | 例 | 説明 |
| :--- | :--- | :--- |
| **個別出力** | `OUT 2,1` | **GPIO 2** を **1(HIGH/ON)** にする。 |
| **一括出力** | `OUT 2` | Bit1(値2)が立つため、**GPIO 2のみON**、他はOFF。 |
| **入力切替** | `OUT 2,-1` | **GPIO 2** を**入力モード**に切り替える。 |
| **2進数指定** | ``OUT `000010 `` | 各ビットに対応するピンを一括制御（Bit1=GPIO 2）。 |

## 5. 主要コマンド一覧

### システム・プログラム制御
- `NEW`: プログラムの消去
- `LIST` [行番号]: プログラムの表示
- `RUN`: 実行
- `SAVE` [番号]: 保存
- `LOAD` [番号]: 読み込み
- `GOTO` 行番号/ラベル: 指定先へジャンプ
- `GOSUB` / `RETURN`: サブルーチン
- `END`: プログラム終了

### 入出力・デバイス制御
- `LED` 0/1: 本体のLED制御
- `WAIT` 数値: 待機（60 = 約1秒）
- `IN()`: デジタル入力の読み取り
- `ANA()`: アナログ入力の読み取り（10bit）
- `OUT` n,m: デジタル出力・プルアップ設定
- `PWM` n,m,p: パルス幅変調（サーボモーター制御等）
- `I2CR` / `I2CW`: I2C通信（読み/書き）
- `UART` n,m: シリアル通信設定

### グラフィック・画面制御
- `CLS`: 画面クリア
- `LOCATE` X,Y: カーソル移動
- `PRINT` : 文字・数値の表示
- `SCR(X,Y)`: 指定座標の文字コード取得
- `SCROLL` 方向: 画面のスクロール

### サウンド
- `BEEP` [音程],[長さ]: 単音を鳴らす
- `PLAY` "MML": 音楽再生（Music Macro Language）

### 数学・論理
- `RND(n)`: 0からn-1までの乱数
- `ABS(n)`: 絶対値
- `SIN(n)` / `COS(n)`: 三角関数（整数近似）
- `BIT(...)`: ビット演算

## 6. 他のBASICでは「使えない/違う」IchigoJamの制限
1. **文字列変数の不在**: `A$="HELLO"` はエラー。`LET A,"HELLO"` とし、`?STR$(A)` で表示。
2. **小数の不在**: `PRINT 1.5` は構文エラー。
3. **ELSEの制限**: 初期のバージョンにはなかったが、1.0以降で対応。
4. **メモリ直接操作**: `PEEK` / `POKE` / `COPY` 等でVRAMやフォント領域を直接書き換えるのが一般的。
5. **マシン語の実行**: `USR()` コマンドでARM Thumbマシン語を直接呼び出し可能。
